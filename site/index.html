Check a page

Paste a page address. RotWatch fetches the page and records the status code and the response time. It then checks each link on the page, up to 100 links. A link is checked with a HEAD request first. If that fails, RotWatch retries with GET. A link counts as broken when it returns a 4xx or 5xx status or when both requests fail.

Some sites return 403 to automated requests even when the page loads fine in a browser. The result shows the status code for each link, so you can judge those cases yourself.

One page per check. Redirects are followed, and the result shows the final address. When a page is larger than 1 MB, only the first 1 MB is read while links are collected. RotWatch keeps no record of the checks you run.

FAQ

What does the page check do?

It fetches one page, records the status code and response time, and checks the links on that page. It does not monitor the page over time. That part is still being built.

Do you keep the addresses I check?

No. A check runs when you submit it, and RotWatch keeps no record of it. The hosting provider keeps standard server logs. The privacy page has the detail.

What counts as a broken link?

A link that returns a 4xx or 5xx status, or one that fails both a HEAD request and a GET retry. Some sites block automated requests and return 403 for pages that load fine in a browser. The result lists the status code for each link, so you can tell those cases apart.

Does the check work on any site?

It works on public pages over HTTP and HTTPS. It does not check pages behind a login, and it refuses private network addresses.
